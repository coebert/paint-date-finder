# Find a walk-on

Please create a new app that will regularly search the internet for paintball events across the UK (such as big games, walk-ons and competitions) and then display these in a calendar. Please include links so that users can easily access the events’ websites to book onto events. Please include a feature that will allow users to browse events chronologically, by type (walk-on, big game etc) or by venue. Please make it possible to manually correct any accidental mistakes/incorrect dates
